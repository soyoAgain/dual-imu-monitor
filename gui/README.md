# MP157 MPU6050 Mac GUI

启动实时模式：

```bash
./run_gui.sh
```

无开发板时使用模拟的 50 Hz 数据检查界面：

```bash
./run_gui.sh --demo
```

程序使用 `pytorch_env` 中的 PyQt5、NumPy 和 Matplotlib。正常模式会自动上传 `tools/monitor_rpmsg_imu.py`，并通过 SSH 读取开发板的 RPMsg IMU 数据。

空间轨迹使用四元数姿态（Mahony 互补滤波）做重力补偿，并在检测到静止时执行零速修正（ZUPT），只用于观察短时间运动趋势，不能作为无漂移绝对位置。左侧可开关重力补偿与 ZUPT、调整滤波系数 α 和姿态增益 kp，并实时显示两种姿态角与静止状态。当前模块 Y 轴饱和时，图 3 与重力校正姿态不可信，界面会给出饱和警告。

图 4 使用纯陀螺积分（无重力校正）显示传感器姿态：固定世界轴、重力方向、机体三轴、线圈法向与线圈平面。它不依赖加速度计，Y 轴饱和时仍可用，但 roll/pitch 会随时间漂移，界面已标注“会漂移”。
