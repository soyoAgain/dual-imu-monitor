# MP157 双传感器 Mac GUI

## 启动与前提

在项目根目录运行：

```sh
./run_gui.sh
```

先确保 `ssh mp157` 可连接、ICM20608 驱动和 `/dev/icm20608` 可用。默认勾选“自动启动 M4，并启用 Linux 开机启动”：每次连接（含重连）都会执行安装脚本，上传本地 `m4/build-arm/m4_rpmsg.elf` 及服务文件，启用服务，并在固件未运行或不匹配时启动它；脚本不负责构建本地固件。关闭此选项时，须自行保证 M4 采样固件已运行且 `/dev/ttyRPMSG0` 存在。

2026-09-21 曾出现板端固件和服务文件为空的情况，当时手动恢复固件与采集，未恢复服务文件。开机启动是否可用须核对服务状态和安装日志，不能仅由本次采集成功推断。详见 [网络诊断](../NETWORK_DIAGNOSIS.md)。

默认使用 `pytorch_env` 的 PyQt5、NumPy、Matplotlib，可通过 `PYTHON_BIN` 指定解释器。正常模式经一条 SSH 流读取 `tools/monitor_dual_imu.py` 的真实双 IMU 数据。点击“开始”后先静止约 2 秒，连续 100 个有效稳定样本满足条件后才初始化；运动时可能等待更久。

`./run_gui.sh --demo` 只用于离线布局和内部诊断，不能作为实机验收或位移精度证明。

## 融合状态与轨迹有效性

左侧 `MPU` / `融合` / `ICM 补偿` / `无效` 描述图 1 的融合状态。MPU Y 可用而 ICM 不可用时，可以继续显示 MPU；MPU Y 不可用且 ICM 也不可用时才不输出融合加速度。

图 3 单独使用完整 ICM 输入，要求 ICM 有效标志、标定、有限三维数据、时间差绝对值 ≤30 ms、非零且未超量程的加速度/角速度均通过检查。失败时暂停传播并清除静止窗口，不回退到 MPU 或拼轴数据。因此图 1 有曲线不代表轨迹可更新。

标定文件默认是 `diagnostic_logs/phase6_accel_calibration/accel_calibration.json`，包含旋转矩阵、加速度偏置和质量指标。缺少标定时仍可查看原始数据，但不能初始化 ICM 轨迹；融合状态还取决于 MPU Y 是否可用。

## ESKF 与显示行为

轨迹由位置、速度、四元数和加速度/陀螺偏置的惯性 ESKF 估计，误差协方差为 15×15。重力补偿始终启用；左侧 α 仅平滑独立 MPU 陀螺姿态显示，不用于 ESKF 输入。旧速度阻尼、kp 和重力补偿开关已移除。

ZUPT 开关控制全部静止观测：最近 20 个有效样本（约 0.4 秒）满足静止判定时，每帧做零速更新，每 5 个确认静止帧另做重力比力和陀螺偏置更新。匀速运动可能被误判为静止，不能仅靠 IMU 保证正确判定。

图 3 只保留最近 10 秒轨迹，独立于左侧时域曲线的“显示窗口”。通过历史位置与当前状态的交叉协方差同步修正历史点，避免旧历史与新端点拼接产生回折。坐标随可见轨迹实时缩放、平移，三轴等比例；静止或空数据时最小跨度 2 mm。删除过期点不重置积分位置；停止保留最后画面，清空会重置曲线、姿态、指标和滤波状态。

无效样本断开积分时间连续性，恢复的首个有效样本仅重建时间基准，不补积分，也不自动重置全部滤波状态。若保留着上一个有效时间基准，遇到时间倒退或间隔超过 0.1 秒会清空重标定。每次重新开始或自动重连都会清空并重新初始化。

算法、默认噪声和历史验证详见 [ESKF 说明](ESKF.md)。

## 断线自动恢复

Mac `AX88772D/en7` 使用手动地址 `169.254.50.1/16`，板端为 `169.254.50.2`。GUI SSH 主连接绑定 en7，连接超时 3 秒，保活间隔 2 秒、最多 3 次未回应。连接退出后等 2 秒重新连接；链路协商、macOS 地址就绪、旧连接退出和 M4 服务准备会增加总恢复时间。

停止会取消待执行的重连，关闭窗口也会取消；SSH/SCP/安装准备阶段支持取消。配置错误也会重试，持续失败时应停止并查看日志。重连后需静置约 2 秒重新初始化 ESKF；极短断线若原 TCP 会话仍存活，可能直接恢复原数据流。

真实拔插实测中，链路恢复后约 7.8 秒建立新会话并恢复 50 Hz 数据，固定 IP 保留。测试关闭了自动安装 M4 选项，该时延不是保证值。见 [重连验收](../diagnostic_logs/network_reconnect_20260921/README.md)。

## 诊断记录

```sh
./run_gui.sh --trajectory-log diagnostic_logs/trajectory.jsonl
```

默认不记录；指定路径后追加原始/融合样本、轨迹输入、预测位移、观测修正、速度、偏置、静止状态与观测次数。停止/关闭时追加平滑历史；开始、清空、停止有事件标记。
