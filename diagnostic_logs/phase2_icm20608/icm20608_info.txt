# ICM20608 Linux 驱动基线信息（阶段二，2026-09-19）

## 内核与模块

- 内核：`5.4.31-g886e225be`
- 模块：`/lib/modules/5.4.31-g886e225be/kernel/drivers/char/icm20608.ko`（10616 字节）
- 加载方式：rootfs 无独立 `insmod/modprobe`，使用 `/bin/busybox modprobe icm20608`
- 已封装为 systemd 服务：`tools/icm20608-load.service` + `tools/icm20608-load.sh`
  - 安装：`sh tools/install_icm20608.sh`
  - 卸载：`sh tools/uninstall_icm20608.sh`（实测可回退并重新安装）
- SPI 设备：`spi0.0`，`modalias=spi:icm20608`，驱动绑定成功
- 内核日志：`ICM20608 ID = 0XAE`（WHO_AM_I 正确）

## 设备节点

```text
crw------- 1 root root 240, 0 /dev/icm20608
```

## 读取 ABI（实测）

- `read()` 固定写入 7 个小端 int32：`gyro_x, gyro_y, gyro_z, accel_x, accel_y, accel_z, temperature`
- **返回值恒为 0**（驱动直接返回 `copy_to_user` 的结果），不能用返回值判断读取成功
- 必须使用固定 28 字节缓冲区调用 `read()`；缓冲区小于 28 字节会被越界写入（实测导致 Python 段错误）
- 因此 `tools/read_icm20608.py` 用 `ctypes` 直接调用 libc `read()`，忽略返回值后解码缓冲区

## 量程与换算（ATK 驱动配置）

| 物理量 | 原始单位 | 换算 |
|---|---|---|
| 加速度 | ±16 g，2048 LSB/g | `raw / 2048 * 9.80665` → m/s² |
| 角速度 | ±2000 dps，16.4 LSB/dps | `raw / 16.4` → °/s |
| 温度 | 326.8 LSB/°C | `raw / 326.8 + 25` → °C |

角速度量程依据：实测最大 317.84 dps 未削顶，排除 ±250 dps；与 ATK 驱动配置一致，阶段四/五会用双传感器交叉标定复核。

## 验收结果（2026-09-19）

1. **静止加速度模长**：`|a|` 均值 9.817 m/s²；静止样本（角速度 < 5 dps）4990 帧，`|a|` 均值 9.811、标准差 0.281 m/s²。
2. **陀螺仪响应**：手动旋转期间角速度模长最大 317.84 dps，887 帧超过 20 dps，方向与幅值合理。
3. **10 分钟连续读取**：6000 帧、605.1 s、平均 9.91 Hz；时间戳最大间隔 0.102 s；温度 34.09 °C（25.00–34.24）；无进程崩溃、无内核 SPI 报错、无新增 eth0 掉线。

## 已知异常

- 10 分钟日志中出现 **4 帧全 0 样本**（0.067%，t≈4483.0、4484.4、4484.5、4484.7），前后数据正常且无运动关联；50 Hz、3000 帧复测未复现；内核无 SPI 错误日志。
- 处理要求：阶段三采集器必须把 ICM20608 全 0 样本标记为无效，不参与融合与标定。
- 环境观察：本次会话中 eth0 曾多次 `Link is Down/Up`（与插拔/线缆移动相关），会造成 SSH 偶发超时；10 分钟测试期间无新增掉线。
