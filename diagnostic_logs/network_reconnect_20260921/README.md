# 固定 IP 与 GUI 自动重连验收（2026-09-21）

Mac 网络服务 AX88772D/en7 经用户在终端输入管理员密码后，设为手动 `169.254.50.1/16`，路由器为空；板端仍为 `169.254.50.2`。Mac SSH 别名 mp157：BindInterface=en7、ConnectTimeout=3、ServerAliveInterval=2、ServerAliveCountMax=3。

GUI 主连接明确设置相同连接/保活参数、BatchMode=yes、ControlPersist=no。连接退出且用户仍希望采集时，2 秒后开始新一轮连接；每轮清空并重新初始化 ESKF。停止或关闭取消重连；准备阶段 SSH/SCP/安装进程可被协作取消并清理本地进程组。

## 实测

- `ssh_disconnect.log`：通过 `ssh -O exit` 中断真实采集主连接，新数据在约 3.127 秒后恢复，确认 ESKF 已重置。随后验证 50 Hz 数据、10 秒轨迹、全部图表、配置刷新、停止/清空/重启及关闭。
- `cancel.log`：实际使用不存在的接口触发 SSH 失败，在重连等待期点击停止，超过重试周期后没有再启动；连接准备阶段关闭也无残留线程。
- `physical_cable.log`：用户物理拔线再插回。链路断开出现在测试第 2.685 秒，恢复在第 9.412 秒；链路恢复的瞬间 IPv4 尚未挂回，稍后固定地址恢复。链路恢复后约 7.801 秒新 SSH 会话重新收到数据，50 Hz、I²C/TX=0/0，重新静止初始化成功。
- `physical_first_attempt.log`：首次脚本过早要求链路恢复瞬间已有 IPv4，断言退出；调整验证脚本为等待地址后重做物理测试并通过。未修改 GUI 来掩盖失败。
- Python 编译和既有 9 项回归通过；窗口退出后板端无残留 monitor_dual_imu 进程。单个连续采集段均不超过 20 秒。

物理测试关闭了“自动启动 M4”选项，使用已运行固件；勾选时可能增加服务检查/安装耗时。7.8 秒是一次实测，不是时延保证。链路重协商、macOS 地址恢复及开发板状态都会影响结果。
